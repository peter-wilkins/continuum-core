# Agent Instructions

## Scope Control

Continuum Core owns Continuum product/domain work: imports, membranes, source
catalogues, public/private Continuum flows, phone snap surfaces, and related
architecture.

If the request clearly belongs to another registered agent or project, do not
absorb it into Continuum context. Say no briefly and name the likely lane, for
example Workflow Manager or JobDone. Do not run routing tools or prepare a
handoff unless Peter explicitly asks for the context guard or clipboard path.

## Working Rules

- Check `git status -sb` before implementation.
- Preserve user data and local/private artifacts.
- Keep changes scoped to Continuum Core unless Peter explicitly redirects.
- Commit and push completed repo changes when implementation work is done.
